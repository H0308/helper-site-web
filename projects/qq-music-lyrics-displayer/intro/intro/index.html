QQ/网易云音乐Windows 10/11任务栏歌词¶

约 4641 个字 预计阅读时间 15 分钟

介绍¶

把 QQ 音乐和网易云音乐的歌词嵌入 Windows 10/11 任务栏——滚动歌词、每日一言、逐字高亮、播放控制、音频频谱，支持Windows 11任务栏上、下、左、右四边布局，程序本体为 C++ 原生实现，无 Electron

软件官网：www.taskbar-lyrics.top

项目核心功能¶

  • 任务栏内嵌歌词：窗口作为任务栏（Shell_TrayWnd）的子窗口，外观贴近 Windows 11 原生媒体卡片——左侧圆角封面 + 歌名/歌手，右侧当前行歌词（超长自动滚动），支持 QQ 音乐和网易云音乐，切歌时歌词内容平滑过渡
  • 四边任务栏与竖向歌词（预览）：Windows 11 26H2 支持任务栏位于上、下、左、右四个位置
  • 三种任务栏展示模式：支持「内嵌」「沉浸」和「Dock 模式」。内嵌模式固定显示在主显示器；沉浸模式覆盖所选显示器的横向任务栏并居中显示歌词，可选择单台或全部显示器（全部时仅覆盖横向任务栏），提供上一首、播放/暂停、下一首、音量、退出、应用收纳、时间与日期、完整托盘菜单和 Windows 系统托盘入口；Dock 模式可显示在指定或全部显示器的顶部/底部，通过 Windows AppBar 为各目标显示器的桌面工作区预留空间，右侧显示频谱及 CPU、内存、网络下行/上行状态，并可在设置中额外开启 GPU 使用率和 CPU 频率；两种展开模式的遮罩不透明度（或模糊程度）可分别调节
  • 多格式歌词与逐字高亮：支持逐字时间轴歌词；逐字歌词按像素进度平滑填充并滚动，LRC 保持整行高亮；当前歌曲没有可用翻译或罗马音时，可选双行歌词，同时显示当前行与下一行预览
  • 翻译与罗马音：可显示部分外文歌曲的翻译或罗马音，并可从设置窗口启用、关闭及切换显示类型
  • QQ 音乐本地歌词：在设置中选择 QQ 音乐本地歌词目录后，程序递归索引本地 QRC 缓存；手动保存的歌词优先，默认按本地→在线获取，本地未命中自动回退在线；托盘菜单可在本地版与在线版之间切换，并可按歌曲持久化选择
  • 双平台自动识别：同时运行 QQ 音乐和网易云音乐时，根据 Windows 当前媒体会话及播放状态自动选择正在播放的来源；切换平台时同步切换歌曲、歌词和控制目标
  • 每日一言与空闲入口：未检测到音乐播放器会话时可保留任务栏入口，显示来自一言、今日诗词或网易云热评的每日一言；支持每天、每 12 小时或每小时更新，缓存当前内容、左/中/右对齐和一键复制，悬浮时显示复制提示并在成功后反馈状态；关闭每日一言后改为按时间与日期类型生成默认欢迎语，也可在设置中自定义欢迎语，每日一言与任务栏歌词之间使用平滑上下转场
  • 快速打开应用：空闲页面提供快速打开区域，可从设置添加本地应用程序地址，最多添加 10 个，支持自定义名称、名称显示开关、点击启动、拖动排序和滚动查看；快速打开区域可展开/收起，并与每日一言、滴答清单今日任务及悬浮媒体卡片平滑切换；同一组应用也可从 Dock 模式的快捷应用入口直接启动
  • Dock 模式伴听宠物：Dock 模式在空闲时让伴听宠物在内容区漫游，播放时在歌词旁伴听，暂停时在旁边休息；切换到其他展示模式或完全停止、极简性能模式时不显示
  • 滴答清单今日任务：可在设置中配置滴答清单网页版用户 API 口令并开启自动同步；程序启动且没有播放器会话时，会在空闲入口中显示一次今日任务概览，空闲卡片可切换到「今日任务」标签查看今天的未完成任务、截止时间和优先级标识；点击任务打开滴答清单网页中的对应详情，点击左侧复选框即可完成任务，成功后从列表移除；支持连接、立即同步和断开连接，API 口令保存于 Windows 凭据管理器，不依赖滴答清单本地客户端
  • 悬浮播放控件与媒体卡片：开启悬浮播放控件后，可选择在歌词区内嵌显示「上一首 / 播放暂停 / 下一首」，或在任务栏外展开独立媒体卡片；媒体卡片显示播放器图标/名称、封面、歌名/歌手、当前进度、总时长和进度条，支持纯色或磨砂玻璃背景，磨砂背景可跟随专辑主色渐变并根据背景明暗自动适配文字颜色，展开/收起和切歌均有平滑过渡，点击播放器图标或名称可打开对应音乐软件；播放中可切换到「每日一言 + 快速打开」组合面板，三类卡片共用展开方式、背景、专辑色跟随和自动适配文字颜色设置
  • 应用音量独立调节：内嵌控件新增音量按钮，悬停弹出音量滑块浮窗；媒体卡片内置音量图标与可展开滑块；通过 WASAPI 音频会话单独调节 QQ 音乐/网易云音乐的音量（对应音量合成器中该应用的一格），不影响系统主音量，支持拖动、滚轮调节和静音
  • 切歌浮窗提示：切歌时在主屏幕中下方（可选中上方）短暂弹出封面、歌名和歌手；弹窗磨砂半透明、置顶，依据背后内容明暗自动适配文字颜色，滑入滑出平滑过渡；可设置停留时长（1~10 秒）、弹出位置，以及前台有全屏应用时不弹出
  • 任务栏歌词背景：可选择无背景、封面模糊（专辑封面高斯模糊后铺满，不透明度可调）或纯色（跟随任务栏深浅色）；背景画在最底层，可与播放进度背景、背景波浪叠加
  • 播放进度背景：从窗口左缘到歌词右缘按播放进度填充专辑主题色（无封面时回退系统强调色），不透明度可调；与频谱的背景波浪互斥
  • 音频频谱：跟随当前播放器（QQ音乐/网易云音乐，其他软件出声不受影响）播放跳动的频谱，可在设置窗口选择默认、柱状图或梦幻波浪样式；梦幻波浪可作为歌曲信息和歌词背景并调节透明度，频谱颜色可以设置跟随已播放歌词颜色、跟随专辑主题色和自定义颜色，支持可以开启颜色渐变，开启时窗口自动加宽、关闭即恢复
  • 任务栏内容动态背景：提供落叶、闪烁星星、二进制和流光粒子四种动态效果，可选择仅待机内容（每日一言或默认欢迎语）、仅歌词或两者显示；独立频谱容器和悬浮卡片不使用该效果，极简模式下关闭
  • 性能模式：在设置窗口或托盘右键菜单切换「正常 / 低渲染 / 完全停止 / 极简」；低渲染将播放动画限制在约 30 FPS 以降低 GPU/CPU 占用，完全停止会隐藏任务栏歌词、停止帧定时器并释放 GPU 资源，但保留当前会话数据，恢复后立即还原；极简模式保持正常歌词刷新率，保留基础歌词显示并将封面效果固定为方形，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗；低渲染、完全停止和极简模式下频谱捕获自动暂停，切回正常模式后恢复，性能模式仅对本次运行有效，重启后恢复正常
  • 任务栏歌词快捷菜单：默认可直接右键任务栏歌词打开精简菜单，快速切换显示、性能模式、内嵌模式任务栏位置、展示模式、Dock 位置、辅助歌词、切换本地/在线歌词（QQ音乐特有）或进入设置；可在「设置 → 显示」中关闭，托盘图标的完整右键菜单不受影响
  • 内嵌模式双锚定位、拖动换位与自动避让：内嵌模式下歌词可锚定在「通知区域左侧」或「任务栏最左侧」，也可按住左键拖动整个任务栏歌词，在两个有效锚点间查看吸附预览，松手后固定并保存位置。Windows 11 下可自动避开小组件、搜索、任务视图、应用图标、TrafficMonitor 和酷狗官方任务栏歌词；空间不足时先在当前空闲区压缩，必要时迁移到更大的空闲区，所有位置都放不下时自动隐藏，并在空间恢复后自动显示。手动重新开启时可选择强制显示，但可能遮挡任务栏按钮。Windows 10 22H2 已测试基本可用，但任务栏防遮挡目前存在兼容性问题
  • 外观自定义：字体、字号、粗体/斜体、歌词颜色、逐字未播放色与不透明度、光晕/描边（颜色独立可调），横向歌词支持左/中/右对齐，左右侧竖向歌词按竖排规则显示，设置持久化；字体颜色与效果支持全局共用或按深色/浅色模式分别配置，已播放色可一键跟随专辑封面主色调
  • Fluent 风格对话框：设置、字体选择、字体颜色与效果、颜色选择、手动搜索歌词、关于窗口以及常用提示/确认窗口统一采用 Windows 11 Fluent 风格；对话框支持手动调整大小并保持最小尺寸与布局比例，为保证拉伸时的渲染稳定使用不透明背景而非 Mica 材质；任务栏歌词与对话框/悬浮窗可分别跟随系统、跟随应用或固定为浅色/深色，设置页部分选项提供与实际界面对应的示意预览，高刷新率下拖动设置窗口时自动使用静态快照，减少拖动延迟
  • 手动搜索歌词：自动匹配错误时可手动搜索并选择正确版本，支持 QQ 音乐、网易云音乐和酷狗歌词候选；对话框可预览逐字滚动或逐行歌词，候选包含翻译或罗马音时可在预览面板独立切换显示；选择结果按平台和歌曲标识分别持久化，下次自动命中
  • 更新检查与安装：关于窗口可选择 GitHub 或 Gitee 作为更新源，查看更新日志、下载并安装更新；开启启动时自动检查后，发现新版本会弹出提示，可直接跳转发布页或进入更新流程
  • 运行日志：托盘菜单可打开运行日志面板，查看当前播放、歌词来源、封面加载来源、CPU/GPU 与专用内存等状态，并可切换查看已成功加载的封面图片；详细运行事件（包括歌词请求与来源、手动搜索、设置/托盘/播放控制、音量、更新，以及资源创建与释放）按会话写入日志文件，并可选择保存目录和定期清理周期
  • 开机自启动：可通过托盘菜单设置随 Windows 登录自动运行，无需管理员权限
  • 歌曲信息和封面隐藏：通过设置窗口设置隐藏歌名、歌手、专辑信息或专辑封面
  • 平台识别图标：可在专辑封面右下角显示当前播放平台图标，便于区分 QQ 音乐和网易云音乐
  • 专辑封面效果：可在默认圆角方形封面与黑胶唱片效果之间切换；黑胶唱片在播放时旋转，暂停时保持当前位置
  • 手动调整歌词进度：对于手动搜索的歌词支持手动提前或者延迟 0.5 秒并持久化
  • 未检测到播放器时的任务栏入口：可在设置中保留或隐藏空闲入口；保留时未检测到音乐播放器会话会显示每日一言或欢迎语（默认或自定义）及快速打开应用，关闭后隐藏任务栏入口

工作原理¶

  • 播放状态：通过 Windows SMTC（System Media Transport Controls）监听已适配的播放器会话。QQ 音乐按 SourceAppUserModelId=QQMusic.exe 识别；网易云音乐目前按 InfLink-rs 写入 SMTC Genres 的 NCM-{歌曲ID} 标识识别。两个平台分别处理时间线和暂停/恢复逻辑，避免互相复用进度状态
  • 歌词来源：QQ 音乐手动保存的歌词优先；启用本地歌词时默认先匹配本地 QRC，未命中再按酷狗 KRC 逐字歌词、QQ 音乐 QRC 逐字歌词和 QQ 音乐 LRC 逐行歌词的在线链路获取，也可从托盘菜单切换到在线版；本地 QRC 对应的原文、翻译和罗马音文件会合并显示。网易云音乐按歌曲 ID 优先获取 YRC 逐字歌词，失败后回退网易云 LRC 逐行歌词。命中后会查询可用的翻译与罗马音，内置 LRU 缓存避免重复请求
  • 滴答清单任务：通过 Dida365 Open API 读取未关闭的任务项目，筛选当前日期范围内的未完成任务并按优先级、标题和截止信息排序；API 口令由 Windows 凭据管理器保存，任务详情通过滴答清单网页打开，完成任务时调用对应 API
  • 音频频谱：WASAPI 进程级回环捕获（ActivateAudioInterfaceAsync，根据当前来源捕获 QQMusic.exe 或 cloudmusic.exe 进程树，Win10 2004+ 原生支持，无驱动无注入）→ 1024 点 FFT（50% 重叠）→ 60Hz~14kHz 对数分 12 频段 →「上升立即、下降平滑」后 60fps 渲染
  • SMTC 适配结构：QQ 音乐和网易云音乐使用独立的播放器适配器，公共层只负责会话监听、来源选择和控制转发，便于后续增加其他播放器
  • 任务栏承载结构：内嵌模式和沉浸模式使用任务栏宿主窗口；沉浸模式覆盖当前任务栏客户区，Dock 模式则切换为 Shell 管理的独立 AppBar，通过 Windows AppBar 协议协商顶部或底部工作区
  • Dock 资源监控：Dock 模式启动独立采样线程，显示系统 CPU、内存以及已连接网络接口的下行/上行速率；可在设置中额外开启 GPU 使用率和 CPU 当前频率，附加指标可在 Dock 资源区滚轮翻页查看；UI 只读取最近一次快照，不在绘制线程执行系统查询

网易云音乐适配¶

网易云音乐桌面版需要额外的 SMTC 增强插件才能提供歌曲 ID 和可靠的播放进度。使用网易云音乐前必须安装 BetterNCM 和 InfLink-rs：

  1. 从 BetterNCM Installer 下载并安装 BetterNCM。

  2. 打开网易云音乐的 BetterNCM 插件商店，搜索并安装 InfLink-rs。

    Tips

    如果插件商店不可用，也可以从 InfLink-rs Releases 下载插件后手动安装。

  3. 按提示重启网易云音乐，再运行或重启 QQMusicLyric.exe。

Note

只安装 InfLink-rs，不要同时安装旧版 InfLink。网易云适配的可用性受 BetterNCM、InfLink-rs 以及网易云音乐客户端版本影响，不保证所有版本均可用。
